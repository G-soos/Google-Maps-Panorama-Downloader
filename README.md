## ✨ Features
* **Ultra High Resolution:** Download tiles and stitch them into massive 8K ($8192 \times 4096$) panoramas.
* **Smart Detection:** Automatically detects both official Street View and User Photospheres.
* **Anti-Ban Logic:** Built-in delays and session management to prevent IP blocking from Google servers.
* **Modern GUI:** Clean, dark-themed interface powered by `CustomTkinter`.
* **Zero Dependencies:** The executable version runs out of the box—no Python installation required.

---

## 🚀 How to Use
1. **Find a Location:** Open Google Maps and drop the yellow "Pegman" into any Street View or 360 photo.
2. **Copy URL:** Copy the full link from your browser's address bar.
3. **Paste & Setup:** Open **360 Extractor**, paste the link, and select your destination folder.
4. **Choose Quality:** Select your desired resolution (2K, 4K, or 8K).
5. **Download:** Hit the button and wait for the magic to happen! 

---

## 🛠️ Technical Details
* **Language:** Python 3.10+
* **Core Libraries:** * `CustomTkinter` (UI Design)
    * `Pillow` (Image Processing & Stitching)
    * `Requests` (Network Management)
* **Optimization:** Uses multi-mirror tile fetching for faster downloads.
